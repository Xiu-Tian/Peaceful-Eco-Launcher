# Peaceful Eco Launcher

**Peaceful Eco Launcher（PEL）** 是一款面向 Minecraft Java 版玩家的 Windows 启动器，将游戏安装、实例管理、资源下载、账户登录与临时联机整合在统一的桌面界面中。

**当前版本：1.0.3 Alpha**  
**推荐环境：Windows 10 / 11 x64**

[下载最新版本](https://github.com/Xiu-Tian/Peaceful-Eco-Launcher/releases) · [项目主页](https://github.com/Xiu-Tian/Peaceful-Eco-Launcher)

> 本仓库用于发布启动器程序和版本信息，项目目前暂不公开源代码。Alpha 版本仍在持续完善中。

## 1.0.3 更新内容

- **临时联机**：支持创建房间、邀请码加入、中转检测与结束联机；显示虚拟 IP、实际 P2P / 中转连接状态，以及房主房间内已连接电脑的主机名。
- **自动检测游戏目录**：识别 PCL2、HMCL 使用的游戏目录，兼容 PCL 的相对路径与 `$` 路径占位符；检测后由用户勾选确认导入。
- **多目录合并管理**：合并展示多个 `.minecraft` 中的游戏版本，可查看来源目录，并将版本迁移到其他游戏目录。
- **统一版本隔离**：各实例使用独立游戏目录，减少存档、配置和模组之间的相互影响，移除原有版本隔离设置。
- **拖动操作**：支持拖动调整游戏列表顺序，以及向模组、光影、材质包和存档管理页拖入文件。
- **光影兼容方案**：纯光影购物车可自动补齐 Fabric API、Sodium、Iris，或生成匹配版本的 Forge + OptiFine 方案。
- **正版登录优化**：支持复制授权码、复制登录链接，并通过系统浏览器完成 Microsoft 登录。
- **资源匹配修复**：修复切换游戏版本时可能复用旧 Fabric API 的问题；确认存在对应页面后才显示 Modrinth、MC 百科跳转按钮。
- **启动自检与日志维护**：启动时检查完整性级别，异常时自动生成修复脚本；定期清理旧启动器日志。
- **界面优化**：改进不同窗口尺寸及缩放比例下的顶部布局，统一反馈窗口的深浅主题、圆角控件与附件区域。

## 主要功能

### 游戏与实例

- 浏览、安装和管理 Minecraft Java 版游戏版本。
- 支持 Fabric、Forge、NeoForge，以及兼容版本的 OptiFine 等附加选项。
- 管理多个实例，分别维护存档、模组、截图、光影与材质包。
- 扫描本机 Java，并提供下载与安装入口。
- 查看官方游戏更新内容、启动任务和下载进度。

### 多个游戏目录

PEL 支持同时管理多个 `.minecraft` 目录，不必将已有游戏集中到一个文件夹。

在左下角打开**存储位置**，可以手动添加目录，或检测其他启动器的游戏目录。检测不会直接改写 PCL2 / HMCL 的配置；勾选并确认后，目录才会加入 PEL。游戏列表会合并展示这些目录中的版本，并支持查看来源、拖动排序和版本迁移。

迁移功能主要移动当前版本目录；若版本存在继承关系，迁移前会检查相关依赖。

### 资源中心与购物车

- 联合搜索 Modrinth 与 CurseForge 的资源。
- 查找模组、整合包、光影和资源包，按游戏版本及加载器筛选。
- 支持中文模组名称与常用中文搜索别名。
- 将资源加入购物车，分析兼容方案，查看文件清单后安装新实例。
- 自动解析可确认的必需前置与冲突；部分 CurseForge 项目的前置仍需查看作者页面确认。
- 支持导入 Modrinth / CurseForge 整合包，以及导出支持格式的实例整合包。

仅加入光影时，购物车会根据实际可用版本分析以下环境：

| 加载器 | 自动匹配的光影运行组件 |
| --- | --- |
| Fabric | Fabric API + Sodium（钠）+ Iris |
| NeoForge | 对应 NeoForge 版本的 Sodium + Iris |
| Forge | 与 Forge 版本匹配的 OptiFine |

以上方案取决于资源和运行组件实际声明的兼容性，并非所有 Minecraft 版本都有完整方案。光影与材质包安装后，仍需在游戏内手动启用。

资源能否直接下载也取决于平台和作者的分发许可。作者不允许第三方分发时，请使用项目的官方页面。

### 拖入本地资源

先选中目标实例，再打开对应管理页，将文件拖入启动器：

| 管理页 | 支持拖入的文件 |
| --- | --- |
| 模组管理 | `.jar` 模组文件 |
| 光影管理 | `.zip` 光影包 |
| 材质包管理 | `.zip` 资源包 |
| 存档管理 | 包含唯一 `level.dat` 的存档 ZIP |

支持一次拖入多个文件。导入目标使用当前实例所属的目录，完成后刷新列表；同名内容不会覆盖，失败时会提示原因。

### 账户与辅助工具

- Microsoft 正版账户、离线账户和 LittleSkin（Yggdrasil）账户管理。
- 在系统浏览器完成正版授权，支持复制授权码与登录链接。
- 深色 / 浅色主题、启动器日志查看和诊断日志导出。
- 内置 DeepSeek 网页，可手动复制所选实例的脱敏游戏日志，方便自行粘贴排查。
- 统一风格的反馈窗口，支持描述问题、附带截图及添加文件；最多 3 个附件（含截图），每个不超过 5 MB。

## 下载与首次运行

1. 前往 [Releases](https://github.com/Xiu-Tian/Peaceful-Eco-Launcher/releases)，下载 `PeacefulEcoLauncher.exe`。
2. 将启动器放入准备长期使用的文件夹，并从 Windows 资源管理器打开。
3. 按提示准备运行环境、选择账户与游戏目录。
4. 在下载页安装游戏，或通过存储位置接入已有的 `.minecraft`。
5. 选择实例，确认 Java 环境后启动游戏。

启动器会检测 .NET Framework 4.8 及兼容版本和 WebView2 Runtime。缺少组件时，会提示并引导从微软官方地址下载安装，执行前验证安装程序的微软签名。

Minecraft 还需要与目标版本匹配的 Java，可使用已有 Java，也可通过启动器下载安装。普通玩家使用发布的 EXE 即可，无需安装 Node.js。

### 首次启动提示修复权限

如果 EXE 被 Windows 以 Low 完整性级别运行，PEL 会在进入主界面前检测到异常，并尝试在启动器旁生成 `Repair-Launcher.cmd`。

关闭提示后，从普通 Windows 桌面或资源管理器双击该脚本。脚本只将对应启动器 EXE 的完整性标记恢复为 Medium，成功后自动重新打开启动器，不改游戏文件或整个目录的权限，也无需管理员权限。

若当前目录无法生成脚本，启动器会显示可在普通命令提示符中执行的修复命令。之后每次启动仍会进行轻量检查，以便发现移动文件后重新出现的异常标记。

## 临时联机使用方法

联机模块目前支持 **Windows x64 与 Minecraft Java 版**。

### 房主

1. 进入单人世界，选择“对局域网开放”，或启动本地 Java 服务端。
2. 在 PEL 联机页填入实际游戏端口；局域网开放端口可能不是默认的 `25565`。
3. 点击**创建联机房间**，将生成的邀请码复制给好友。
4. 保持启动器、房间和游戏世界运行。

### 好友

1. 在联机页粘贴房主的完整邀请码，点击**加入房间**。
2. 加入后，在 Minecraft 多人游戏中使用 PEL 显示的本地连接地址。
3. 双方使用兼容的游戏版本及模组配置。

联机优先使用 P2P 直连，无法直连时使用当前配置的中转节点；界面显示虚拟 IP 和实际连接方式。房主可查看已连接电脑的主机名列表，列表每 5 秒刷新。该列表表示加入临时网络的电脑，不等同于已经进入游戏世界的玩家列表。

邀请码包含房间密钥，仅分享给信任的好友。公共中转节点的可用性受网络和服务器状态影响。

## 日志与问题反馈

启动器数据通常位于 EXE 旁的 `Launcher` 文件夹；遇到写入权限限制时，部分数据会使用用户缓存位置。实际路径可在首页或存储位置中查看。

- **启动前失败**：查看 `Launcher/logs/bootstrap.log`。
- **启动器或游戏问题**：在日志页面查看并导出诊断日志。
- **联机执行失败**：查看 `Launcher/multiplayer/logs/bridge.log`。
- **提交反馈**：点击界面的**反馈**，说明操作步骤、实际表现及预期结果，并按需要添加文件。

超过 14 天的旧启动器日志会自动清理：启动时执行一次，持续运行期间每 6 小时检查一次；超过 8 MB 的固定启动器日志会在启动时轮转。当前正在使用的日志和游戏会话日志不在旧启动器日志删除范围内。

## 隐私与联网说明

- Microsoft 与第三方账户登录会连接对应认证服务；账户敏感凭据使用 Windows 当前用户的数据保护机制保存。
- DeepSeek 网页与 PEL 的启动器功能接口隔离。游戏日志需要手动复制和粘贴，PEL 不会自动把游戏日志发送给 DeepSeek 网页。
- 可选的 DeepSeek API Key 用于资源介绍翻译；未填写时使用备用翻译服务或显示原始介绍。
- 反馈和异常报告可能包含启动器版本、系统环境、异常堆栈、近期日志及所选附件；发送前请确认附件中没有不希望分享的内容。
- 联机功能会在临时网络中使用电脑主机名，供房主识别已连接的电脑。

## 自动更新

PEL 已接入本项目的 GitHub Releases 更新检查。发布符合格式的更新包后，可在启动器中检查并下载更新；下载过程验证 SHA-256，安装更新前需要确认重启，并提供失败回滚机制。

自动检查与下载可在设置中控制。是否有可用更新，以启动器检测到的 Release 和可验证安装包为准。
