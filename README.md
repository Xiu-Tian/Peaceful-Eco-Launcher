# Peaceful Eco Launcher

PEL 是一个 Windows 上的 Minecraft Java 版启动器。装游戏、找模组、理存档，或者临时开个房间和朋友玩，都可以在这里完成。

**当前版本：1.1.6 BetaFix** · **适用系统：Windows 10 / 11（x64）**

[下载启动器（GitHub Releases）](https://github.com/Xiu-Tian/Peaceful-Eco-Launcher/releases) · [夸克网盘](https://pan.quark.cn/s/30adaf0cf935#/list/share)

PEL 不开源。GitHub 页面用于提供下载和版本公告，不提供启动器源码。

## 第一次用 PEL

下载 `PeacefulEcoLauncher.exe`，先把它放到打算长期使用的文件夹里，再双击打开。按提示选账号和游戏目录，就可以去「下载」页安装游戏了。若系统缺少 .NET Framework 4.8 或 WebView2，启动器会给出提示。

**已经装过游戏？** 不用重新下载。打开「存储位置 → 导入或找回游戏目录」，可以检测 PCL2、HMCL 或旧版 PEL 的目录，也可以手动添加 `.minecraft`。导入只是登记位置，不会移动或删除你的文件。

**有正版账号？** 选 Microsoft 登录，会跳到系统浏览器授权，不需要在 PEL 里输入微软密码。你也可以使用离线账号或 LittleSkin。把启动器发给别人时，只发 EXE，不要连同保存登录信息的 `Launcher` 文件夹一起发。

## 平时能用它做什么

- **装版本和整合包。** 支持原版和 Fabric、Forge、NeoForge 等加载器。缺少合适的 Java 时，可以在启动器里下载安装。
- **找模组、光影和材质包。** 在资源页搜索 Modrinth 和 CurseForge，按游戏版本和加载器筛选。选了好几个模组时，可以先放进购物车，再一起确认前置和安装内容。
- **管理已有版本。** 点左侧游戏列表里的实例，就能管理它的模组、存档、截图、光影和材质包。常用的键位和模组配置也可以存成预设，换版本时不用从头调。

## 和朋友联机

房主先在单人世界里点「对局域网开放」，把游戏显示的端口填到 PEL 的「联机」页，再创建房间。把邀请码发给好友，好友在 PEL 加入房间后，用页面给出的地址连接 Minecraft 多人游戏。

别把端口一律填成 `25565`，以游戏里显示的为准。游玩时房主需要让游戏和 PEL 都保持运行；如果用的是整合包，也记得先对齐双方的游戏版本和模组。邀请码只发给要一起玩的人。

## 更新和反馈

主页的「启动器更新」可以检查新版。如果下载被夸克客户端接管，下载完成后可以回到 PEL，点「导入更新包」手动选择 EXE。

遇到问题，可以点启动器右上角的「反馈」。说一下**在哪个页面、点了什么、出现了什么提示**，比只发一句「打不开」更容易定位。有截图或日志可以一并附上，发送前记得遮掉个人信息。

如果连主界面都打不开，可以先找启动器数据目录下的 `Launcher\logs\startup-latest.txt` 和 `launcher-errors.log`；游戏启动失败的话，先看报错里有没有提示所需的 Java 版本。
