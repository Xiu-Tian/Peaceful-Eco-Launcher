# Peaceful Eco Launcher

Peaceful Eco Launcher（PEL）是一款面向 **Minecraft Java 版**玩家的 Windows 启动器。它将游戏安装、实例管理、资源搜索、账户切换和常用辅助工具整合在简洁的桌面界面中。

> 当前版本：**1.0.1 Alpha**  
> 本仓库用于发布启动器程序和版本信息；项目目前暂不公开源代码。

## 主要功能

- **安装与管理游戏**：浏览 Minecraft 版本，安装游戏并管理多个实例。
- **管理游戏加载器**：支持 Fabric、Forge、NeoForge 等常用加载器。
- **实例隔离**：分别管理不同实例的存档、模组和配置，降低版本之间相互影响。
- **资源中心**：联合搜索 Modrinth 与 CurseForge，支持模组类型筛选、版本与加载器匹配，以及资源购物车批量安装。
- **多类资源支持**：查找模组、整合包、光影和资源包；可导入 Modrinth 与 CurseForge 整合包。
- **账户管理**：支持 Microsoft 正版账户、离线账户和 LittleSkin（Yggdrasil）账户。
- **Java 管理**：扫描本机 Java，并提供下载与安装入口。
- **DeepSeek 网页**：在启动器内使用 DeepSeek 网页，并可手动复制脱敏后的最近一次游戏日志。日志不会自动发送给 DeepSeek。
- **日志与故障排查**：查看启动器日志、游戏启动记录，并导出诊断日志。
- **深色与浅色主题**：根据偏好切换界面主题。

## 下载与运行

1. 打开本仓库的 **Releases** 页面。
2. 下载最新版本中的 `PeacefulEcoLauncher.exe`。
3. 双击启动器，按照界面提示完成首次运行设置。

PEL 会在首次运行时检测 .NET Framework 4.8 及兼容版本和 WebView2 Runtime。若缺少组件，启动器会提示并引导从微软官方地址下载安装；下载的安装程序会先验证微软签名。

运行 Minecraft 还需要安装合适版本的 Java。PEL 可以检测已有环境，也可以协助下载 Java。

## 资源下载须知

资源中心会联合展示 Modrinth 与 CurseForge 的内容，并根据游戏版本和加载器提供筛选。资源能否直接下载取决于作者和平台的分发许可；如果某个 CurseForge 文件不允许第三方启动器分发，PEL 会提示使用该项目的官方页面。部分 CurseForge 模组前置需要玩家自行查看并确认。

光影与资源包下载后不会自动启用，实际使用还取决于对应的加载器或运行组件。

## 隐私说明

- DeepSeek 网页与 PEL 的启动器功能接口隔离。
- 复制游戏日志需要用户手动操作；日志会进行敏感信息脱敏，PEL 不会自动将其发送给 DeepSeek。
- 设置中的 DeepSeek API Key 为可选项，用于资源介绍翻译；不填写时会使用备用翻译服务或显示原始介绍。
- 登录 Microsoft 或第三方账户时，启动器会与相应认证服务通信。

## 自动更新

启动器已包含 GitHub Releases 更新检查、下载校验和失败回滚功能，并可在设置中控制自动检查与下载。更新通道需要完成本项目公开仓库配置后启用；安装更新前会由用户确认重启。

## 反馈与问题

遇到安装、启动或资源下载问题时，请先在启动器的日志页面导出诊断日志，再通过项目提供的反馈渠道联系开发者。发送日志前请确认内容中不包含不希望分享的信息。
